# 🎧 Spotify Music Clustering & Recommendation Engine

Unsupervised machine learning system clustering 32,000+ tracks into acoustic archetypes using PCA dimensionality reduction, $k$-Means clustering, and cosine-similarity vector recommendations.

---

## 🛠️ Tech Stack & Methodology
* **Language & Storage:** Python, DuckDB SQL, Pandas, NumPy, Parquet
* **Machine Learning:** Scikit-Learn (StandardScaler, PCA, $k$-Means, Cosine Similarity)
* **Visualizations:** Matplotlib, Seaborn
